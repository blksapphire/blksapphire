## `04 / Engineering Philosophy`

```text
        IDEA
         │
         ▼
      PROTOTYPE
         │
         ▼
       TEST IT
         │
    ┌────┴────┐
    │         │
   WORK     BREAK
    │         │
    │         ▼
    │       DEBUG
    │         │
    └────┬────┘
         │
         ▼
       REBUILD
         │
         ▼
       SHIP IT
```

> I learn more from a system that breaks than one that was never pushed.

I care about **understanding why something works**, not just getting it to work once.

That means experimenting, measuring, breaking things, reading the source, rebuilding the architecture and trying again.
